What changed on the portal

The City doesn't announce when it adds, removes, renames or rewrites a dataset. This log finds those changes by comparing each day's snapshot of the catalog with the one before it. A rewritten description often carries news — an agency noting a feed has stopped, or that fields with names and addresses were pulled.

Snapshots have been taken daily since April 30, 2026. Removals are only logged after a dataset is missing from two consecutive snapshots and the portal itself no longer serves it, because the City's catalog API occasionally drops an item for a day.
